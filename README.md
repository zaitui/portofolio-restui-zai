# Portfolio Restui Zai

Portfolio website personal dengan HTML, CSS, dan JavaScript.

## Struktur
- `index.html` — halaman utama
- `style.css` — desain
- `script.js` — menu mobile + animasi
- `assets/profile.jpg` — foto profil

## Deploy ke Vercel
1. Buat repository baru di GitHub, misalnya `portfolio-restui-zai`.
2. Upload semua isi folder ini ke repository.
3. Login ke Vercel dengan GitHub.
4. Pilih **Add New → Project**.
5. Pilih repository tersebut.
6. Klik **Deploy**.
7. Vercel akan memberikan alamat `*.vercel.app`.

## Catatan
- Ganti teks/deskripsi project di `index.html` bila ingin disesuaikan.
- Link GitHub, Instagram, dan WhatsApp sudah dipasang.
- Tidak membutuhkan database atau build command.
